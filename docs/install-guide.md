# คู่มือติดตั้งและเชื่อมฐานข้อมูล

## 1. ติดตั้งบน Windows (แนะนำสำหรับร้านทั่วไป)

1. ดับเบิลคลิก `FlexPOS-Setup.exe` → เลือกโฟลเดอร์ติดตั้ง → เสร็จสิ้น
   (Windows อาจเตือน “Unknown publisher” เพราะไฟล์ยังไม่ได้ลงลายเซ็นดิจิทัล กด *More info → Run anyway*)
2. เปิดโปรแกรม FlexPOS จะเห็นตัวช่วยตั้งค่าร้าน 7 ขั้นตอน
3. ข้อมูลเก็บที่ `%APPDATA%\FlexPOS\data` (ฐานข้อมูล, ไฟล์สำรอง, config)

> ถ้าไฟร์วอลล์ Windows ถามเรื่องการเข้าถึงเครือข่าย ให้ **อนุญาตในเครือข่ายส่วนตัว** เพื่อให้แท็บเล็ต/มือถือพนักงานเชื่อมต่อได้

## 2. รูปแบบการใช้งาน

| แบบ | เหมาะกับ | ตั้งค่า |
|---|---|---|
| เก็บในเครื่องนี้ (SQLite) | ร้านเดียว 1–5 เครื่อง | เลือก “เก็บในเครื่องนี้” ในตัวช่วย |
| หลายเครื่องในวง LAN | เครื่องหลัก + จุดขายเพิ่ม/แท็บเล็ต | เครื่องหลักติดตั้งแบบแรก เครื่องอื่นเลือก “เชื่อมเครื่อง Host” หรือเปิดเบราว์เซอร์ไปที่ `http://<IP เครื่องหลัก>:4100` |
| ฐานข้อมูลของร้าน | หลายสาขา / มีเซิร์ฟเวอร์อยู่แล้ว | เลือก “ฐานข้อมูลของฉัน” หรือใช้ Docker |

ดู IP ของเครื่องหลักได้ที่ **ตั้งค่า → อุปกรณ์และเครือข่าย** (มี QR สำหรับแอปพนักงานและจอลูกค้า) — แนะนำตั้ง IP คงที่ให้เครื่องหลักที่เราเตอร์

## 3. เชื่อม PostgreSQL / MySQL

1. สร้างฐานข้อมูลว่างและผู้ใช้ เช่น PostgreSQL:
   ```sql
   CREATE USER flexpos WITH PASSWORD 'รหัสผ่านที่ปลอดภัย';
   CREATE DATABASE flexpos OWNER flexpos;
   ```
   MySQL/MariaDB (ต้องเป็น utf8mb4):
   ```sql
   CREATE DATABASE flexpos CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   CREATE USER 'flexpos'@'%' IDENTIFIED BY 'รหัสผ่านที่ปลอดภัย';
   GRANT ALL ON flexpos.* TO 'flexpos'@'%';
   ```
2. ในตัวช่วยเลือก “ฐานข้อมูลของฉัน” กรอก host/port/user/password/database → **ทดสอบการเชื่อมต่อ** → ถัดไป
3. ระบบสร้างตารางให้อัตโนมัติ รหัสผ่านถูกเข้ารหัส (AES-256-GCM ผูกกับเครื่อง) ก่อนบันทึกใน config

ย้ายจาก SQLite ไปฐานข้อมูลอื่น: สำรองข้อมูลที่เครื่องเดิม → ติดตั้งใหม่และเลือกฐานข้อมูลใหม่ → ตั้งค่า → สำรองข้อมูล → กู้คืนจากไฟล์

## 4. Docker (เซิร์ฟเวอร์/คลาวด์)

```bash
# แก้รหัสผ่านใน docker-compose.yml ก่อน
docker compose up -d --build
```
เปิด `http://<server>:4100` · ตัวแปรที่ใช้ได้:

| ตัวแปร | ความหมาย |
|---|---|
| `FLEXPOS_DB_URL` | `postgres://user:pass@host:5432/db`, `mysql://…`, หรือ `sqlite:/data/flexpos.db` |
| `FLEXPOS_DATA_DIR` | ที่เก็บ config/ไฟล์สำรอง (ค่าเริ่มต้น `/data`) |
| `PORT` | พอร์ต (ค่าเริ่มต้น 4100) |

ถ้าเปิดให้ใช้ผ่านอินเทอร์เน็ต ต้องวางหลัง reverse proxy ที่มี HTTPS (เช่น Caddy/Nginx) เสมอ

## 5. เครื่องพิมพ์

- **เครื่องพิมพ์ใบเสร็จ/ครัวแบบ LAN/Wi-Fi** (ESC/POS พอร์ต 9100): ตั้งค่า → เครื่องพิมพ์ → ค้นหาในเครือข่าย หรือกรอก IP → ทดสอบพิมพ์ ใช้ “โหมดภาพ” เพื่อพิมพ์ภาษาไทยได้ทุกรุ่น
- **USB/Bluetooth**: ติดตั้งไดรเวอร์ใน Windows แล้วเพิ่มเครื่องพิมพ์แบบ “เครื่องพิมพ์ที่ติดตั้งใน Windows” ใส่ชื่อเครื่องพิมพ์เพื่อพิมพ์อัตโนมัติ (ใช้ได้ในโปรแกรม FlexPOS บน Windows)
- เครื่องพิมพ์ครัว/บาร์ต้องเป็นแบบ LAN เพื่อให้ทุกเครื่อง (รวมแอปมือถือ) สั่งพิมพ์ได้ ใบที่พิมพ์ไม่สำเร็จจะเข้าคิวและพิมพ์เองเมื่อเครื่องกลับมา
