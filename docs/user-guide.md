# คู่มือผู้ใช้ FlexPOS

> ในโปรแกรมมีหน้า **ช่วยเหลือ** (เมนูรูปผู้ใช้ → ช่วยเหลือ) และกด **Ctrl+K** เพื่อค้นหาเมนูได้ทุกหน้า

## เริ่มวันขาย
1. เข้าสู่ระบบด้วย PIN
2. หน้า **ขาย** จะขอให้เปิดกะ — นับเงินทอนในลิ้นชักแล้วกรอกยอด

## ขายสินค้า
- แตะสินค้า หรือ **สแกนบาร์โค้ดได้เลย** ไม่ต้องคลิกช่องค้นหา
- ค้นหาด้วยชื่อ/SKU (F2) พิมพ์หลายคำได้ เช่น `ลาเต้ เย็น`
- สินค้าที่มีตัวเลือก (ไซซ์ ความหวาน ฯลฯ) จะมีหน้าต่างให้เลือก
- แตะรายการในตะกร้าเพื่อแก้จำนวน ราคา ส่วนลด หรือหมายเหตุ
- **เลือกสมาชิก** (F4) เพื่อสะสมแต้มและรับส่วนลดสมาชิกอัตโนมัติ
- **ส่วนลดบิล / คูปอง** (F8) · **พักบิล** (F6) · **เรียกบิล/เลือกโต๊ะ** (F7)
- ถ้าไม่มีสิทธิ์ทำรายการ ระบบจะขอ **PIN ผู้จัดการ**

## รับเงิน (F12)
| วิธี | ขั้นตอน |
|---|---|
| เงินสด | กดปุ่มธนบัตรหรือพิมพ์จำนวน ระบบแสดงเงินทอน → Enter |
| PromptPay | ลูกค้าสแกน QR (ยอดใส่ให้อัตโนมัติ) ตรวจยอดเข้าในแอปธนาคาร → ยืนยัน |
| แบ่งจ่าย | ใส่ยอดของวิธีแรก → “แบ่งจ่าย” → เลือกวิธีถัดไป |
| ค้างชำระ | ต้องเลือกสมาชิกก่อน และอยู่ในวงเงิน |
| ใบกำกับภาษีเต็มรูป | ติ๊ก “ออกใบกำกับภาษีเต็มรูป” กรอกชื่อ/เลขผู้เสียภาษี |

ถ้าอินเทอร์เน็ต/เครือข่ายหลุด เครื่องลูกยังรับเงินได้ บิลจะแสดง “รอส่ง” และส่งเองเมื่อกลับมาออนไลน์

## ร้านอาหาร
- หน้า **โต๊ะ** แตะโต๊ะว่างเพื่อเปิดบิล → เลือกเมนู → **ส่งครัว**
- พนักงานเสิร์ฟใช้ **แอปรับออเดอร์**: สแกน QR ที่ ตั้งค่า → อุปกรณ์และเครือข่าย แล้ว “เพิ่มไปยังหน้าจอหลัก”
- เก็บเงิน: เปิดบิลโต๊ะที่หน้าขาย → ชำระเงิน · ย้าย/รวมโต๊ะได้จากปุ่มชื่อบิล
- จอครัว: แตะรายการเพื่อเปลี่ยนสถานะ ใหม่ → กำลังทำ → พร้อมเสิร์ฟ (พนักงานเสิร์ฟได้รับแจ้งเตือน)

## หลังขาย
- **บิล**: ค้นหา พิมพ์ซ้ำ ยกเลิกบิล คืนสินค้า ออกใบกำกับภาษีย้อนหลัง
- **กะ** → ปิดกะ: นับธนบัตร ระบบคำนวณส่วนต่าง → พิมพ์ Z Report

## จัดการร้าน
- **สินค้า**: เพิ่ม/แก้ไข นำเข้า Excel (ดาวน์โหลดไฟล์ตัวอย่างในหน้าต่างนำเข้า) ลากจัดเรียงปุ่มหน้าขาย
- **สต็อก**: รับสินค้าเข้า ปรับ (ต้องระบุเหตุผล) นับสต็อก
- **สมาชิก / โปรโมชั่น / รายงาน** · **ตั้งค่า**: ข้อมูลร้าน ใบเสร็จ ภาษี วิธีชำระ โมดูล สี/ธีม พนักงานและสิทธิ์ ฟิลด์เพิ่มเติม เครื่องพิมพ์ สำรองข้อมูล
