# FlexPOS Cloud — แดชบอร์ดร้านค้าออนไลน์

FlexPOS Cloud ให้ผู้จัดการร้านดูยอดขาย รายงาน และแก้ไขข้อมูลหลักของร้านผ่านหน้าเว็บได้จากทุกที่ ส่วนเครื่อง POS ที่ร้านยังเป็นตัวหลักและขายได้ตามปกติแม้ไม่มีอินเทอร์เน็ต

```
เครื่อง POS ที่ร้าน (ฐานข้อมูลของร้าน)  ──ส่งข้อมูลเมื่อออนไลน์──►  FlexPOS Cloud (PostgreSQL แยกต่างหาก)
         ▲                                                    │
         └────── การแก้ไขสินค้า/ราคา/ลูกค้าจากเว็บ ◄───────────┘          ผู้จัดการ/ผู้ดู ล็อกอินผ่านเว็บ
```

## ลูกค้าเลือกได้ 3 แบบ (ตอนตั้งค่าร้าน หรือ ตั้งค่า → แดชบอร์ดออนไลน์)

| แบบ | ข้อมูลออนไลน์อยู่ที่ | ดูผ่านเว็บ |
|---|---|---|
| **FlexPOS Cloud** (แนะนำ) | เซิร์ฟเวอร์ของผู้ให้บริการ `https://strata-pos.itdev.in.th` | ได้ |
| **เซิร์ฟเวอร์ของร้านเอง** | เซิร์ฟเวอร์ที่ร้านติดตั้ง FlexPOS Cloud เอง (ดูหัวข้อ "ติดตั้งบนเซิร์ฟเวอร์ของร้าน") | ได้ |
| **เก็บในเครื่องนี้อย่างเดียว** | เครื่อง POS เท่านั้น ไม่ส่งข้อมูลออก | ไม่ได้ (ระบบจะเตือนและให้ยืนยันก่อน) |

## การทำงานเมื่อเครื่อง POS ปิดหรือเน็ตหลุด
- ทุกการเปลี่ยนแปลงในฐานข้อมูลของร้านถูกจดไว้ในคิว (`sync_outbox`) ด้วย trigger ของฐานข้อมูล จึงไม่ตกหล่นไม่ว่าจะมาจากหน้าจอไหน
- เครื่อง POS ส่งข้อมูลทันทีหลังขาย (ภายใน ~2 วินาที) และตรวจทุก 30 วินาที ถ้าส่งไม่ได้จะลองใหม่ห่างขึ้นเรื่อย ๆ (สูงสุด 5 นาที)
- หน้าเว็บแสดงข้อมูลล่าสุดที่ได้รับ พร้อมแถบแจ้ง "เครื่อง POS ออฟไลน์ กำลังแสดงข้อมูล ณ …" เมื่อเครื่องกลับมาออนไลน์ ข้อมูลที่ค้างจะส่งขึ้นและหน้าเว็บอัปเดตเองแบบเรียลไทม์ (WebSocket)
- การส่งซ้ำไม่ทำให้ข้อมูลซ้ำ (upsert ตามรหัสแถว)
- รหัสผ่านและ PIN ของพนักงาน, refresh token, คิวพิมพ์ ไม่ถูกส่งออกจากเครื่อง

## บัญชีและสิทธิ์บนเว็บ
- **ผู้จัดการ** — บัญชีที่สร้างตอนเชื่อมต่อเครื่อง POS ดูทุกอย่างของร้านตัวเอง แก้ไขข้อมูลหลัก เพิ่ม/ลบผู้ใช้เว็บ ยกเลิกการเชื่อมต่อเครื่อง POS
- **ผู้ดูข้อมูล** — ผู้จัดการเพิ่มให้ได้ที่แท็บ "ผู้ใช้เว็บ" ดูแดชบอร์ด รายงาน และข้อมูลได้อย่างเดียว
- บัญชีหนึ่งเห็น **เฉพาะร้านที่ตัวเองเป็นสมาชิก** ข้อมูลแต่ละร้านแยกอยู่คนละ schema ในฐานข้อมูล
- **Superadmin** (ผู้ให้บริการ) — เห็นและจัดการทุกร้าน: สร้าง/แก้ไข/ระงับ/ลบร้าน, จัดการบัญชีทั้งหมดและสิทธิ์รายร้าน, เปิดดู/แก้ไขทุกตารางในฐานข้อมูล, รันคำสั่ง SQL แบบอ่านอย่างเดียว, ดู log การใช้งานบนคลาวด์ / log รับข้อมูลจาก POS / log ที่เครื่อง POS / log ของเซิร์ฟเวอร์

## แก้ไขข้อมูลจากเว็บ
- แก้ได้: สินค้า หมวดหมู่ ราคา ตัวเลือกเสริม ลูกค้า กลุ่มลูกค้า โปรโมชั่น วิธีชำระเงิน ผู้จำหน่าย การตั้งค่าร้าน
- การแก้ไขเข้าคิวรอส่งไปเครื่อง POS (แท็บ "การแก้ไขจากเว็บ" แสดงสถานะ รอส่ง / ส่งถึง POS แล้ว / POS ปฏิเสธ) ถ้าเครื่องออฟไลน์จะถูกใช้เมื่อเครื่องกลับมาออนไลน์
- บิลขาย กะ และการเคลื่อนไหวสต็อก แก้ไขได้ที่เครื่อง POS เท่านั้น (POS เป็นต้นฉบับของข้อมูลการขาย)
- ลบสินค้าจากเว็บ = ซ่อนสินค้า (soft delete) เพื่อไม่ให้ประวัติการขายเสีย

## ติดตั้งเซิร์ฟเวอร์ FlexPOS Cloud บน Debian 13 (สำหรับผู้ให้บริการ)

### 1. เตรียม Cloudflare (โดเมน `strata-pos.itdev.in.th`)
แนะนำ **Cloudflare Tunnel** ไม่ต้องเปิดพอร์ตบนเซิร์ฟเวอร์
1. Cloudflare Dashboard → Zero Trust → Networks → Tunnels → Create a tunnel (Cloudflared) ตั้งชื่อ `flexpos-cloud`
2. คัดลอก **token** ของ tunnel
3. Public Hostname: `strata-pos.itdev.in.th` → Service `HTTP` `127.0.0.1:4200`
4. SSL/TLS → Edge Certificates: เปิด Always Use HTTPS, Network: เปิด WebSockets

### 2. ติดตั้ง
คัดลอกโฟลเดอร์โปรแกรม FlexPOS ไปที่เซิร์ฟเวอร์ (เช่น `git clone` หรือ `scp`) แล้วรัน:
```bash
sudo DOMAIN=strata-pos.itdev.in.th CF_TUNNEL_TOKEN=<token> SUPERADMIN_EMAIL=you@example.com \
     bash deploy/cloud/install-debian.sh
```
สคริปต์จะ:
- ติดตั้ง PostgreSQL 17, Node.js 22, cloudflared
- สร้างฐานข้อมูล `flexpos_cloud` + รหัสผ่านและ JWT secret แบบสุ่ม เก็บใน `/etc/flexpos-cloud.env` (สิทธิ์ 640)
- build และติดตั้งโปรแกรมที่ `/opt/flexpos-cloud` รันเป็น systemd service `flexpos-cloud` ด้วยผู้ใช้ระบบ `flexpos-cloud` (ฟังที่ 127.0.0.1:4200 เท่านั้น)
- สำรองฐานข้อมูลทุกวัน 03:15 ไว้ที่ `/var/backups/flexpos-cloud` (เก็บ 14 วัน) และหมุน log ที่ `/var/log/flexpos-cloud`
- สร้างบัญชี superadmin (ถามรหัสผ่าน)

อัปเดตเวอร์ชัน: ดึงโค้ดใหม่แล้วรันคำสั่งเดิมอีกครั้ง (ฐานข้อมูล การตั้งค่า และ secret เดิมถูกเก็บไว้)

### 3. ตรวจสอบ
```bash
systemctl status flexpos-cloud
journalctl -u flexpos-cloud -f
curl https://strata-pos.itdev.in.th/api/health
```

### ทางเลือก: Cloudflare proxied DNS + nginx
ใช้ไฟล์ตัวอย่าง `deploy/cloud/nginx-cloudflare.example.conf` (Origin Certificate, SSL Full strict) และเปิดพอร์ต 443 เฉพาะ IP ของ Cloudflare

### การตั้งค่าใน `/etc/flexpos-cloud.env`
| ตัวแปร | ความหมาย |
|---|---|
| `DATABASE_URL` | PostgreSQL ของคลาวด์ (แยกจากเครื่อง POS ของลูกค้าทั้งหมด) |
| `JWT_SECRET` | secret สำหรับ session (≥ 32 ตัวอักษร) |
| `ALLOW_SIGNUP` | `1` = ลูกค้าสร้างร้าน+บัญชีผู้จัดการเองได้ตอนเชื่อมต่อ POS, `0` = superadmin ต้องสร้างร้านให้ก่อน |
| `TZ` | เขตเวลาที่ใช้คิด "วันนี้" ในแดชบอร์ด (`Asia/Bangkok`) |
| `LOG_FILE` | ไฟล์ log ที่ superadmin เปิดดูได้บนเว็บ |

## ติดตั้งบนเซิร์ฟเวอร์ของร้าน (ลูกค้าโฮสต์เอง)
- Debian/Ubuntu: ใช้ `deploy/cloud/install-debian.sh` เหมือนด้านบน (ใส่โดเมนของร้าน)
- Docker: แก้รหัสผ่านใน `docker-compose.cloud.yml` แล้ว `docker compose -f docker-compose.cloud.yml up -d` และสร้าง superadmin ของร้านตามคำแนะนำในไฟล์
- ต้องมี HTTPS ด้านหน้า (Cloudflare Tunnel, nginx, Caddy) แล้วใส่ที่อยู่ `https://…` ในเครื่อง POS ที่ ตั้งค่า → แดชบอร์ดออนไลน์ → เซิร์ฟเวอร์ของร้านเอง

## สำหรับนักพัฒนา
```bash
pnpm --filter @flexpos/cloud dev        # API :4200 (ใช้ PGlite ใน apps/cloud/data ถ้าไม่ตั้ง DATABASE_URL)
pnpm --filter @flexpos/cloud-web dev    # เว็บ :5174 (proxy /api → :4200)
cd apps/cloud && npx tsx src/main.ts create-superadmin --email admin@example.com --password 'xxxxxxxx'
pnpm --filter @flexpos/cloud test       # ทดสอบ (PGlite ไม่ต้องติดตั้ง PostgreSQL)
```
- โค้ด: `apps/cloud` (เซิร์ฟเวอร์), `apps/cloud-web` (หน้าเว็บ), `packages/reports` (คิวรีแดชบอร์ด/รายงานที่ใช้ร่วมกับ POS จึงได้ตัวเลขตรงกัน), `apps/server/src/services/cloudSync.ts` (ตัวส่งข้อมูลฝั่ง POS)
