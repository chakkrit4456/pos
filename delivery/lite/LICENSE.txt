FlexPOS Lite — ข้อตกลงการใช้งานซอฟต์แวร์ (End User License Agreement)
===============================================================================

การติดตั้งหรือใช้งาน FlexPOS Lite ("ซอฟต์แวร์") ถือว่าท่านยอมรับข้อตกลงนี้

1. สิทธิ์การใช้งาน
   ท่านได้รับสิทธิ์ใช้งานซอฟต์แวร์แบบไม่ผูกขาด โอนให้ผู้อื่นไม่ได้ และไม่มีวันหมดอายุ
   สำหรับร้านเดียว บนคอมพิวเตอร์ 1 เครื่อง ต่อ 1 License key โดย key ผูกกับ
   Machine ID ของเครื่องนั้น

2. ข้อห้าม
   ห้ามใช้ License key เดียวกับหลายเครื่อง ห้ามขายต่อ ให้เช่า แจกจ่าย หรือแบ่งปัน
   ซอฟต์แวร์หรือ License key ให้ผู้อื่น ห้ามลบประกาศลิขสิทธิ์ และห้ามดัดแปลงหรือ
   หลบเลี่ยงระบบตรวจสอบ License หรือข้อจำกัดการใช้งาน 1 เครื่อง

3. การย้ายเครื่อง
   หากเปลี่ยนคอมพิวเตอร์ ให้ติดต่อผู้จำหน่ายเพื่อออก key สำหรับเครื่องใหม่
   key ของเครื่องเดิมจะใช้ต่อไม่ได้

4. ข้อมูลของท่าน
   ข้อมูลการขายและข้อมูลร้านเก็บอยู่ในคอมพิวเตอร์ของท่าน หากเปิดใช้แดชบอร์ดออนไลน์
   จะมีสำเนาส่งไปยังบริการ FlexPOS Cloud ที่ท่านเลือก รหัสผ่านและ PIN ของพนักงาน
   ไม่ถูกส่งออกจากเครื่อง ท่านมีหน้าที่สำรองข้อมูลเอง (ตั้งค่า -> สำรองข้อมูล)

5. การอัปเดตและการสนับสนุน
   เป็นไปตามที่ระบุในหน้าสินค้า ณ วันที่ซื้อ

6. ไม่มีการรับประกัน
   ซอฟต์แวร์ให้บริการ "ตามสภาพ" โดยไม่มีการรับประกันใดๆ ท่านมีหน้าที่ตรวจสอบว่า
   ใบเสร็จ ใบกำกับภาษี และรายงาน เป็นไปตามกฎหมายที่เกี่ยวข้อง

7. การจำกัดความรับผิด
   ภายในขอบเขตที่กฎหมายอนุญาต ผู้ขายไม่รับผิดต่อความเสียหายทางอ้อม การสูญเสียกำไร
   หรือข้อมูลอันเกิดจากการใช้ซอฟต์แวร์ ความรับผิดรวมไม่เกินราคาที่ท่านชำระ

8. การสิ้นสุด
   สิทธิ์การใช้งานสิ้นสุดทันทีหากท่านละเมิดข้อตกลงนี้ และท่านต้องหยุดใช้และลบสำเนา
   ทั้งหมด
