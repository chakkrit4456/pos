FlexPOS Lite — ระบบขายหน้าร้านสำหรับร้านค้าและร้านขายของชำ
Version 1.0.0
===============================================================================

ขอบคุณที่เลือกใช้ FlexPOS Lite ระบบขายหน้าร้านขนาดเบาสำหรับร้านขายของชำ
มินิมาร์ท และร้านค้าทั่วไป สแกนบาร์โค้ดขายได้ทันที รองรับบาร์โค้ดจากตาชั่ง
ทำงานบนคอมพิวเตอร์ Windows ของร้าน ขายต่อได้แม้ไม่มีอินเทอร์เน็ต


ในแพ็กเกจนี้มีอะไรบ้าง
-------------------------------------------------------------------------------
  FlexPOS-Lite-Setup.exe     ตัวติดตั้งสำหรับ Windows (เริ่มที่ไฟล์นี้)
  Getting-Started.html       คู่มือเริ่มต้นใช้งานพร้อมภาพประกอบ (เปิดด้วยเบราว์เซอร์)
  images/                    ภาพหน้าจอที่ใช้ในคู่มือ
  LICENSE.txt                ข้อตกลงการใช้งาน
  README.txt                 ไฟล์นี้


เริ่มใช้งานใน 5 นาที
-------------------------------------------------------------------------------
  1. ดับเบิลคลิก FlexPOS-Lite-Setup.exe แล้วทำตามขั้นตอน
     (ถ้า Windows SmartScreen ขึ้นเตือน กด "More info" -> "Run anyway")
  2. เปิด "FlexPOS Lite" จากไอคอนบนหน้าจอ
  3. ตัวช่วยตั้งค่าร้าน: ใส่ชื่อร้าน เลือก "ร้านขายของชำ" ตั้งรหัสผ่านและ PIN
     และเปิดข้อมูลตัวอย่างเพื่อทดลอง
  4. เปิดกะ แล้วยิงบาร์โค้ดสินค้า กด F12 เพื่อรับเงิน

คู่มือฉบับเต็มพร้อมภาพหน้าจอ: เปิด Getting-Started.html


FlexPOS Lite มีอะไรบ้าง
-------------------------------------------------------------------------------
  - หน้าขายแบบรายการ เน้นสแกนบาร์โค้ด ตะกร้าเต็มจอ เสียงบี๊ปเมื่อสแกน
  - พิมพ์ 3*รหัส เพื่อขาย 3 ชิ้นในครั้งเดียว
  - สินค้าชั่งน้ำหนัก: บาร์โค้ดจากตาชั่ง (น้ำหนักหรือราคา) และปุ่มน้ำหนักด่วน
  - สแกนเจอบาร์โค้ดที่ยังไม่มีในระบบ เพิ่มสินค้าใหม่ได้ทันที
  - หน่วยขาย (ชิ้น/แพ็ค/ลัง) ระดับราคา สินค้าราคาเปิด
  - สต็อก รับเข้า นับสต็อก แจ้งเตือนใกล้หมด ล็อตและวันหมดอายุ
  - สมาชิก แต้มสะสม ขายเชื่อ (ลูกหนี้)
  - PromptPay QR เงินสด โอน บัตร ใบกำกับภาษี
  - กะการทำงาน รายงาน สำรองข้อมูล บันทึกการใช้งาน แดชบอร์ดออนไลน์

  ไม่มีใน Lite (มีใน FlexPOS ตัวเต็ม): ผังโต๊ะ จอครัว แอปรับออเดอร์ ตัวเลือกสินค้า
  โปรโมชั่น บทบาทและสิทธิ์แบบกำหนดเอง ฟิลด์เพิ่มเติม หลายเครื่อง/หลายสาขา


ความต้องการของระบบ
-------------------------------------------------------------------------------
  คอมพิวเตอร์    : Windows 10 หรือ 11 (64-bit), RAM 4 GB, พื้นที่ว่าง 1 GB
  หน้าจอ       : 1280 x 720 ขึ้นไป
  เครื่องสแกน    : เครื่องสแกนบาร์โค้ด USB (แบบคีย์บอร์ด) ใช้ได้ทันที ไม่ต้องตั้งค่า
  ตาชั่ง        : ตาชั่งพิมพ์ฉลากบาร์โค้ด EAN-13 (รหัสนำหน้า 21-29)
  เครื่องพิมพ์   : เครื่องพิมพ์ใบเสร็จ 58/80 มม. แบบ USB หรือเครือข่าย
  อินเทอร์เน็ต   : ไม่จำเป็นสำหรับการขาย ใช้เฉพาะแดชบอร์ดออนไลน์
