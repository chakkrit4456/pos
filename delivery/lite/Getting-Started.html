1. ติดตั้ง

  1. ดับเบิลคลิก FlexPOS-Lite-Setup.exe แล้วทำตามขั้นตอน (ถ้ามี SmartScreen กด More info → Run anyway)
  2. เปิด FlexPOS Lite จากไอคอนบนหน้าจอ
ติดตั้งคู่กับ FlexPOS ตัวเต็มบนเครื่องเดียวกันได้ ข้อมูลของแต่ละโปรแกรมแยกกัน

2. ตั้งค่าร้าน (ทำครั้งเดียว)

3. ขายด้วยการสแกน

  1. เข้าสู่ระบบด้วย PIN แล้ว เปิดกะ พร้อมนับเงินทอนเริ่มต้น
  2. ยิงบาร์โค้ดได้ทันที ช่องสแกนพร้อมรับเสมอ รายการใหม่จะขึ้นท้ายตารางพร้อมเสียงบี๊ป
  3. หรือพิมพ์ชื่อ/SKU แล้วกด Enter ถ้าเจอหลายรายการระบบจะแสดงสินค้าให้เลือก

4. สินค้าชั่งน้ำหนัก

ตาชั่งพิมพ์ฉลากบาร์โค้ด

ตั้ง SKU ของสินค้าชั่งน้ำหนักเป็นรหัส 5 หลักเดียวกับในตาชั่ง (เช่น 00123) แล้วยิงฉลากจากตาชั่งได้เลย ระบบอ่านน้ำหนักหรือราคาจากบาร์โค้ด EAN-13 รูปแบบ PP IIIII VVVVV C

  • PP รหัสนำหน้า 21–29 (20 ใช้กับบาร์โค้ดภายในร้าน)
  • IIIII รหัสสินค้า 5 หลัก · VVVVV น้ำหนักเป็นกรัม หรือราคาเป็นสตางค์
  • ตัวอย่าง 2100123015009 = หมูสับ 1.500 กก.

ปรับรหัสนำหน้าและชนิดค่า (น้ำหนัก/ราคา) ได้ที่ ตั้งค่า → หน้าขาย → บาร์โค้ดจากตาชั่ง

ชั่งที่หน้าร้าน

แตะสินค้าชั่งน้ำหนัก แล้วเลือกปุ่มน้ำหนักด่วน หรือพิมพ์น้ำหนักเป็นกรัม

5. รับเงิน

6. สินค้าและสต็อก

  • นำเข้าสินค้าจาก Excel/CSV ได้ที่หน้า สินค้า → นำเข้า
  • ตั้งหน่วยขาย เช่น ชิ้น/แพ็ค 6/ลัง พร้อมบาร์โค้ดของแต่ละหน่วย
  • พิมพ์สติกเกอร์บาร์โค้ดสำหรับสินค้าที่ไม่มีบาร์โค้ด

7. หลังร้าน

8. License: 1 License = 1 เครื่อง

  • ทดลองใช้ฟรี 14 วัน
  • ส่ง Machine ID จากหน้า ตั้งค่า → License ให้ผู้จำหน่ายเพื่อรับ License key ของเครื่องนี้ แล้วกด เปิดใช้งาน
  • FlexPOS Lite เปิดได้เฉพาะบนเครื่องที่ติดตั้ง แท็บเล็ตหรือเครื่องอื่นในวง LAN เชื่อมเข้ามาไม่ได้
  • เปลี่ยนคอมพิวเตอร์: ติดต่อผู้จำหน่ายเพื่อออก key ให้เครื่องใหม่
