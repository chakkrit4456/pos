FlexPOS — ระบบขายหน้าร้าน (ร้านอาหาร คาเฟ่ และร้านค้า)
Version 1.0.0
===============================================================================

ขอบคุณที่เลือกใช้ FlexPOS ระบบขายหน้าร้านแบบครบชุดสำหรับร้านอาหาร คาเฟ่
เบเกอรี่ บาร์ และร้านค้าทั่วไป ทำงานบนคอมพิวเตอร์ Windows ของร้านเอง ขายต่อได้
แม้ไม่มีอินเทอร์เน็ต และดูยอดขายผ่านแดชบอร์ดออนไลน์ได้ทุกที่


ในแพ็กเกจนี้มีอะไรบ้าง
-------------------------------------------------------------------------------
  FlexPOS-Setup.exe          ตัวติดตั้งสำหรับ Windows (เริ่มที่ไฟล์นี้)
  Getting-Started.html       คู่มือเริ่มต้นใช้งานพร้อมภาพประกอบ (เปิดด้วยเบราว์เซอร์)
  images/                    ภาพหน้าจอที่ใช้ในคู่มือ
  LICENSE.txt                ข้อตกลงการใช้งาน
  README.txt                 ไฟล์นี้


เริ่มใช้งานใน 5 นาที
-------------------------------------------------------------------------------
  1. ดับเบิลคลิก FlexPOS-Setup.exe แล้วทำตามขั้นตอน
     (ถ้า Windows SmartScreen ขึ้นเตือน กด "More info" -> "Run anyway")
  2. เปิด "FlexPOS" จากไอคอนบนหน้าจอ
  3. ตัวช่วยตั้งค่าร้านจะเปิดขึ้น เลือก:
       - ฐานข้อมูล: "เก็บในเครื่องนี้" (แนะนำ)
       - ชื่อร้าน ที่อยู่ และการตั้งค่าภาษี
       - ประเภทธุรกิจ: ร้านอาหาร คาเฟ่ ร้านค้าปลีก ร้านขายของชำ ฯลฯ
       - ชื่อเจ้าของ รหัสผ่าน และ PIN
       - แดชบอร์ดออนไลน์: FlexPOS Cloud + License key
         (หรือ "เก็บในเครื่องนี้อย่างเดียว" ถ้าไม่ต้องการดูผ่านเว็บ)
       - ข้อมูลตัวอย่าง: เปิดไว้เพื่อทดลองกับเมนูและโต๊ะตัวอย่าง
  4. เปิดกะ แตะสินค้า รับเงิน เริ่มขายได้ทันที

คู่มือฉบับเต็มพร้อมภาพหน้าจอ: เปิด Getting-Started.html


ฟีเจอร์ของ FlexPOS (ตัวเต็ม)
-------------------------------------------------------------------------------
  - หน้าขายแบบปุ่มสินค้าหรือแบบรายการ สแกนบาร์โค้ด ตัวเลือกสินค้า (ขนาด/ท็อปปิ้ง)
  - ผังโต๊ะ ทานที่ร้าน/กลับบ้าน ส่งครัว จอครัว (KDS) แอปรับออเดอร์ QR
  - โปรโมชั่น สมาชิกและแต้มสะสม ขายเชื่อ
  - สต็อก ล็อตและวันหมดอายุ หลายสาขา
  - หลายเครื่องในร้าน (แท็บเล็ต/มือถือผ่าน Wi-Fi) จอแสดงผลฝั่งลูกค้า
  - บทบาทและสิทธิ์พนักงานแบบกำหนดเอง ฟิลด์เพิ่มเติม
  - PromptPay QR ใบกำกับภาษี รายงาน สำรองข้อมูล บันทึกการใช้งาน


ความต้องการของระบบ
-------------------------------------------------------------------------------
  เครื่องหลัก   : Windows 10 หรือ 11 (64-bit), RAM 4 GB, พื้นที่ว่าง 1 GB
  หน้าจอ       : 1280 x 720 ขึ้นไป รองรับจอสัมผัส
  อุปกรณ์เสริม  : แท็บเล็ต/มือถือ/PC ที่มีเบราว์เซอร์ ใน Wi-Fi เดียวกัน ไม่ต้องติดตั้ง
  เครื่องพิมพ์   : เครื่องพิมพ์ใบเสร็จ ESC/POS 58/80 มม. แบบเครือข่าย หรือเครื่องพิมพ์
                 ที่ติดตั้งใน Windows (รวมถึง USB)
  อินเทอร์เน็ต   : ไม่จำเป็นสำหรับการขาย ใช้เฉพาะแดชบอร์ดออนไลน์

  - ใส่ key ที่ ตั้งค่า -> License หรือในขั้นตอน "แดชบอร์ดออนไลน์" ของตัวช่วยตั้งค่า
