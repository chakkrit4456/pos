FlexPOS

ระบบขายหน้าร้านสำหรับร้านอาหาร คาเฟ่ และร้านค้า — คู่มือเริ่มต้น เวอร์ชัน 1.0.0

1. ติดตั้ง

  1. ดับเบิลคลิก FlexPOS-Setup.exe แล้วทำตามขั้นตอน (ถ้ามี SmartScreen กด More info → Run anyway)
  2. เปิด FlexPOS จากไอคอนบนหน้าจอ ตัวช่วยตั้งค่าร้านจะเปิดขึ้นอัตโนมัติ

2. ตั้งค่าร้าน (ทำครั้งเดียว)

3. การขาย

  1. เข้าสู่ระบบด้วย PIN แล้ว เปิดกะ พร้อมนับเงินทอนเริ่มต้น
  2. แตะสินค้า หรือยิงบาร์โค้ดได้ทันทีโดยไม่ต้องคลิกช่องค้นหา
  3. กด F12 หรือปุ่ม ชำระเงิน เลือกเงินสด PromptPay QR โอน หรือบัตร
ร้านขายของชำหรือมินิมาร์ทเปลี่ยนเป็นหน้าขาย แบบรายการ (สแกนเป็นหลัก) ได้ที่ ตั้งค่า → หน้าขาย

4. โต๊ะและครัว

5. สินค้าและสต็อก

6. อุปกรณ์และเครื่องพิมพ์

  • แท็บเล็ตหรือมือถือใน Wi-Fi เดียวกันเปิดลิงก์ที่ ตั้งค่า → อุปกรณ์และเครือข่าย ได้ทันที
  • เพิ่มเครื่องพิมพ์ใบเสร็จ ครัว หรือบาร์ ที่ ตั้งค่า → เครื่องพิมพ์

7. แดชบอร์ดออนไลน์

ดูยอดขายผ่านเว็บได้ทุกที่ที่ strata-pos.itdev.in.th ข้อมูลที่ขายตอนออฟไลน์จะส่งขึ้นอัตโนมัติเมื่อกลับมาออนไลน์

8. License

  • ทดลองใช้ฟรี 14 วัน จากนั้นใส่ License key ที่ ตั้งค่า → License
  • key เดียวใช้ได้หลายเครื่องในร้านตามแพ็กเกจ และไม่มีวันหมดอายุ
สำรองข้อมูลสม่ำเสมอที่ ตั้งค่า → สำรองข้อมูล
